# e-plantShopping

e-PlantShopping is a React-based plant shopping application developed as part of a hands-on web development lab.

##Features
Browse a collection of plants
View plant information and prices
Add plants to the shopping cart
Increase or decrease item quantities
Remove items from the cart
View the total cart amount
Responsive user interface

##Technologies Used
React
JavaScript
HTML
CSS
Redux
Git and GitHub

##Getting Started
1. Clone the repository
git clone <repository-url>
2. Navigate to the project
cd e-PlantShopping
3. Install dependencies
npm install
4. Start the development server
npm start

The application will then be available at the local development URL shown in the terminal.

##Purpose

This project demonstrates the use of React components, state management, Redux, event handling, and dynamic rendering to build a simple e-commerce application.
